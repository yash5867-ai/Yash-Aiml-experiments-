⚙️ Installation & Execution

1. Python Programs

Install Python 3 and follow these steps:

git clone YOUR_REPOSITORY_URL

Navigate to the project folder:

cd AI-Prolog-Practicals

Run any Python practical:

python "Yash ex 13.py"

Replace the filename with the practical you want to execute.

2. Prolog Programs

1. Install "SWI-Prolog" (https://www.swi-prolog.org/).
2. Open SWI-Prolog.
3. Load the required Prolog file.

Example:

consult('Yash ex 2.pl').

4. Enter the required query to execute the program.
